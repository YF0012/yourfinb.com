# yourfinb.com

Website for **Your FinB – Your Finance Buddy**.

Single-page site (`index.html`) with five views: Home, Services, How we work, Who we help and Contact.
Everything (styles, scripts, logo and Earth textures) is inside `index.html`; the only external
resources are Google Fonts and three.js r128 from cdnjs.

## Run locally
Open `index.html` in a browser, or serve the folder:

    python3 -m http.server 8000

## Publish with GitHub Pages
Settings → Pages → Source: "Deploy from a branch" → Branch: `main` / root.
